# ATM MACHINE

ATM machine project using Java, Maven, JDBC and PostgreSQL.

## Features

- Register
- Login
- Create account
- Check balance
- Deposit
- Withdraw
- Transfer
- Transaction history

## Tech

Java  
Maven  
JDBC  
PostgreSQL

## Run

1. Create `atm_db` in PostgreSQL or u can name a database as u want but I recommded to use atm_db as a database name 
2. Configure the database connection.
3. Run the Maven project.
4. Start `Main.java`.
